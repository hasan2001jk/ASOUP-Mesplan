# МЕСПЛАН — установка службы на сервер

Служба `mesplan.jar` (порт 8687). На сервере 198.1.2.246 она сейчас не работает —
ставится как новая. Пароли в JAR не зашиты: задаются в xml обёртки.

## Что нужно

- Папка, например `D:\mesplan\`.
- Java — та же, что у AsoupServer: `C:\Program Files\Java\jdk1.8.0_65`.
  **Не новее**: старый SQL Server принимает только TLS 1.0.
- WinSW (как у служб `asoupserver` и «Asoup microservice for taxes»): скопировать
  их `.exe` под именем `mesplan.exe`.
- `mesplan.jar` из `build/libs/` (сборка: `gradlew bootJar`).

## mesplan.xml

```xml
<service>
  <id>mesplan</id>
  <name>Mesplan</name>
  <description>Заявки МЕСПЛАН, порт 8687</description>
  <executable>C:\Program Files\Java\jdk1.8.0_65\bin\java.exe</executable>
  <arguments>-Dfile.encoding=UTF-8 -jar "%BASE%\mesplan.jar"</arguments>
  <env name="MESPLAN_DB_PASSWORD" value="ПАРОЛЬ_БАЗЫ"/>
  <env name="MESPLAN_AUTH_MODE" value="log"/>
  <env name="JWT_SECRET" value="СЕКРЕТ_BACKEND_AUTH"/>
  <env name="MESPLAN_FILES_DIR" value="D:\mesplan\files"/>
  <log mode="roll-by-size"/>
  <onfailure action="restart" delay="10 sec"/>
</service>
```

- `MESPLAN_DB_PASSWORD` — пароль входа к базе `mesplan` (сейчас `sa`, тот же, что
  в старом `application.properties`). Без него служба не запустится и напишет об этом.
- `MESPLAN_AUTH_MODE`:
  - `off` — без проверки входа (пока на сервере старый Backend-Auth);
  - `log` — всё пропускает, отказы только пишет в журнал;
  - `enforce` — без входа 401, без роли МЕСПЛАН 403. Включать **только после** `log`
    и проверки журнала: при ошибке в секрете фронт выкинет пользователей из системы.
- `JWT_SECRET` — тот же секрет, что у Backend-Auth (нужен в `log` и `enforce`).
- `MESPLAN_FILES_DIR` — папка, куда служба кладёт загруженные файлы заявок как есть;
  из них собирается «Ответный файл». Папку не чистить: без исходного файла ответ
  будет собран в стандартной ширине полей. Создаётся сама.

## Установка

```bat
cd /d D:\mesplan
mesplan.exe install
mesplan.exe start
```

Проверка — в браузере с сервера: `http://localhost:8687/api/dictionaries/przsob`
отвечает списком (в `enforce` — 401, это тоже значит «служба работает»).
Журнал — `D:\mesplan\mesplan.out.log`: при запуске строка «Started MesplanApplication».

## Откат

```bat
mesplan.exe stop
mesplan.exe uninstall
```
Раздел МЕСПЛАН вернётся в прежнее состояние (не работает). Данные в базе служба
не удаляет; таблицы и схему не меняет (`ddl-auto=none`).
